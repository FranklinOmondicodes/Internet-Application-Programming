# WebLab — Internet Application Programming

A beginner-friendly static website demonstrating HTML, CSS, JavaScript and image assets.

## Files
- `index.html` — page structure and content
- `css/style.css` — styling and responsive layout
- `js/script.js` — interactive features
- `images/` — two local SVG illustrations

## Run locally
Open `index.html` in a web browser, or open the project folder in Visual Studio Code and use the Live Server extension.

## Publish with GitHub Pages
1. Upload all files and folders to the root of a public GitHub repository.
2. Ensure `index.html` is in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish the site.

The contact form is a front-end demonstration: it validates the entries but does not send or store messages. Google Fonts are optional; fallback fonts are provided.
