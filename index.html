ABOUT THIS WEBSITE

Learn by building.

This example website demonstrates the main parts of a simple front-end web application. It includes page structure, responsive styling, local images and interactive JavaScript features.

01

Structure with HTML

Organise headings, paragraphs, navigation, images, links and forms using meaningful elements.

02

Style with CSS

Choose colours, fonts, spacing and layouts. Responsive rules make the website fit different screens.

03

Interact with JavaScript

Respond to clicks, update page content, validate form entries and control the theme.
